# 🎓 Kariyer Rehberi

Üniversite öğrencilerinin kariyer yolculuklarını daha bilinçli ve planlı bir şekilde şekillendirmelerine yardımcı olmak amacıyla geliştirdiğim interaktif bir web platformudur.

## 🚀 Proje Hakkında

**Kariyer Rehberi**, öğrencilerin ilgi alanlarına ve kariyer hedeflerine göre kendilerini geliştirebilecekleri alanları keşfetmelerini, çeşitli teknoloji ve meslek alanları hakkında bilgi edinmelerini ve kariyer süreçlerini daha sistematik bir şekilde planlamalarını amaçlar.

Bu proje aynı zamanda web geliştirme, kullanıcı arayüzü tasarımı ve frontend geliştirme konularında kendimi geliştirmek amacıyla oluşturduğum projelerden biridir.

## ✨ Özellikler

* 🎯 Kariyer alanlarını keşfetme
* 💻 Teknoloji ve meslek alanları hakkında içerikler
* 📚 Öğrenme kaynaklarına yönlendirme
* 🧭 Öğrencilerin kariyer yolculuğunu planlamasına yardımcı olacak yapı
* 🎨 Modern ve kullanıcı dostu arayüz
* 📱 Farklı ekran boyutlarına uyumlu tasarım

## 🛠️ Kullanılan Teknolojiler

* HTML5
* CSS3
* JavaScript

## 🎯 Projenin Amacı

Bu projeyi geliştirirken temel amacım yalnızca bir web sitesi oluşturmak değil; aynı zamanda frontend geliştirme, kullanıcı deneyimi ve proje geliştirme süreçlerinde pratik kazanmaktı.

İlerleyen aşamalarda projeye daha fazla interaktif özellik, kullanıcı sistemi ve kişiselleştirilmiş kariyer önerileri eklenmesi planlanmaktadır.

## 🔮 Gelecek Geliştirmeler

* [ ] Kullanıcı kayıt/giriş sistemi
* [ ] Kişiselleştirilmiş kariyer önerileri
* [ ] Öğrenme yol haritaları
* [ ] Kullanıcı ilerleme takibi
* [ ] Backend entegrasyonu
* [ ] Veritabanı desteği
